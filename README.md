# طقسنا — تطبيق توقعات الطقس (PWA)

تطبيق ويب بيشتغل زي تطبيق موبايل عادي: بتقدر تثبته على الشاشة الرئيسية، وبيفتح بدون شريط المتصفح.

## المميزات
- تدور على أي بلد / محافظة / مدينة بالعربي أو الإنجليزي (فيوم، مصر، القاهرة... إلخ)
- زرار 📍 يجيب موقعك الحالي أوتوماتيك
- تختار أي تاريخ:
  - **من النهاردة لحد 15 يوم قدام** → توقع حقيقي دقيق (من Open-Meteo)
  - **تاريخ فات** → بيانات أرشيف فعلية لو متاحة
  - **بعيد عن 15 يوم قدام** → بيوريلك **متوسط تاريخي** لنفس اليوم من آخر 5 سنين، وبيوضحلك إنه مش توقع مؤكد 100%
- شريط أيام سريع تحت الكارت تقدر تدوس عليه تنقل بين الأيام بسرعة
- خلفية متحركة (سماء، شمس/قمر، سحاب) بتتغير حسب حالة الطقس

## ليه مش قادر يتثبت على الموبايل دلوقتي؟
عشان يظهر زرار "إضافة للشاشة الرئيسية"، لازم الموقع يكون:
1. شغال على **HTTPS** (مش file:// على جهازك)
2. فيه Service Worker شغال (موجود بالفعل في الملفات: `service-worker.js`)
3. فيه `manifest.json` صحيح (موجود بالفعل)

يعني لازم **ترفع الملفات دي على استضافة** الأول. أسهل طريقة مجانية:

### الطريقة الأسهل: GitHub Pages
1. اعمل حساب على GitHub (لو معندكش)
2. اعمل Repository جديد، وارفع كل الملفات اللي في المجلد ده (`index.html`, `style.css`, `app.js`, `manifest.json`, `service-worker.js`, ومجلد `icons`)
3. من إعدادات الـ Repository → Pages → فعّل النشر من فرع main
4. هياخد لك رابط زي: `https://username.github.io/repo-name/`
5. افتح الرابط ده من موبايلك بمتصفح Chrome أو Safari → هيظهرلك خيار "إضافة للشاشة الرئيسية" أو زرار التثبيت جوه التطبيق

### أو: Netlify / Vercel (سحب وإفلات)
- ادخل على netlify.com، اعمل حساب، واسحب المجلد كامل في صفحة "Deploy" → هياخد رابط HTTPS جاهز فورًا، بدون Git.

## تشغيل تجريبي على جهازك (اختياري، للمعاينة بس)
```
cd اسم-المجلد
python3 -m http.server 8080
```
افتح `http://localhost:8080` على المتصفح. **ملحوظة:** زرار التثبيت مش هيشتغل على localhost بنفس الشكل الكامل على كل الأجهزة، فالأفضل الرفع على HTTPS فعلي زي فوق.

## تخصيص لاحق
- الأيقونات جوه `icons/` بسيطة (شمس + أهرامات)، لو حابب تغيّرها استبدل `icon-192.png` و`icon-512.png` بنفس المقاسات.
- لو عايز تضيف مصادر طقس تانية أو لغة تانية، الملف الأساسي للمنطق هو `app.js`.
